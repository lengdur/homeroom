🚀 Configurar Base de Datos en Supabase

Sigue estos pasos para crear las tablas necesarias

⚠️ Importante

Si recibiste el error "permission denied for schema public", sigue estos pasos usando la interfaz de Supabase.

1
Ir a Supabase
Abre https://supabase.com e ingresa a tu proyecto jtfqkiwfyynysyqrvmjz
2
Acceder a SQL Editor
En el menú izquierdo, haz clic en "SQL Editor"
3
Crear nuevo Query
Haz clic en "New Query" (botón azul en la parte superior)
4
Copiar y ejecutar el SQL
Copia el siguiente código SQL y pégalo en el editor:
-- Crear tabla usuarios CREATE TABLE IF NOT EXISTS usuarios ( id UUID DEFAULT gen_random_uuid() PRIMARY KEY, email TEXT UNIQUE NOT NULL, password TEXT, created_at TIMESTAMPTZ DEFAULT NOW() ); -- Crear tabla preguntas CREATE TABLE IF NOT EXISTS preguntas ( id UUID DEFAULT gen_random_uuid() PRIMARY KEY, email TEXT NOT NULL, pregunta TEXT NOT NULL, created_at TIMESTAMPTZ DEFAULT NOW(), CONSTRAINT fk_usuarios FOREIGN KEY (email) REFERENCES usuarios(email) ); -- Crear índices CREATE INDEX IF NOT EXISTS idx_usuarios_email ON usuarios(email); CREATE INDEX IF NOT EXISTS idx_preguntas_email ON preguntas(email);
5
Ejecutar SQL
Presiona Ctrl+Enter o haz clic en el botón "RUN" (parte superior derecha)
6
Verificar éxito
Si todo funciona, verás un mensaje de éxito y deberías ver las tablas usuarios y preguntas en el panel izquierdo bajo "Tables"
